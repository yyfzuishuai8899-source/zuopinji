使用仅授权此网站仓库的 GitHub 授权码管理内容。访客不需要登录；只有有写入权限的账号才能保存修改。

首次使用：如何获取授权码
  1. 打开 GitHub 授权设置，登录你的 yyfzuishuai8899-source 账号。
  2. 名称填写“作品集管理”，设置有效期。
  3. Repository access 选择 Only select repositories，仅选 zuopinji。
  4. Repository permissions 中将 Contents 设置为 Read and write。Metadata 保留默认读取权限，其他权限不用开。
  5. 点击 Generate token，将生成的授权码粘贴到上方。不要发到聊天里，也不要放进网站文件。

授权码只保存在当前页面内存中，关闭或刷新后需要重新连接；不会存进草稿或仓库。到期后可重新生成。

修改完成后点击“保存并发布”。上传文件暂存后，需保存才会展示给访客。移除素材会从新版网站删除，仓库历史仍有记录。视频单个最多 50 MB；总容量接近上限时会提示。公开视频无法完全防止下载或录屏。
